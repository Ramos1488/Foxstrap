## ✨ Особенности
*   **Эксклюзивный дизайн:** Полностью переработанный интерфейс в стиле Fox.
*   **Оптимизация:** Твики для стабильного FPS и минимального отклика.
*   **Легкость:** Ничего лишнего, только то, что нужно для комфортной игры.
*   **Полная совместимость:** Базируется на последней версии Bloxstrap.

## 🚀 Установка
1. Перейдите в раздел [Releases](ссылка_на_релизы).
2. Скачайте последнюю версию `.exe` или `.zip`.
3. Запустите и следуйте инструкциям установщика.
