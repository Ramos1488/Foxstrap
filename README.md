# 🦊 Foxstrap

![Platform](https://img.shields.io/badge/platform-Windows-blue?style=for-the-badge)
![Status](https://img.shields.io/badge/status-stable-brightgreen?style=for-the-badge)

**Foxstrap** — это кастомная модификация и лаунчер для Roblox, построенный на базе Bloxstrap. Он создан для тех, кто ценит скорость, минимализм и расширенные возможности настройки игрового клиента.

---

## 🔥 Основные возможности

*   🚀 **Оптимизация:** Улучшенная загрузка и минимальное потребление системных ресурсов.
*   🎨 **Dark Glass UI:** Современный интерфейс в стиле Glassmorphism с неоновыми акцентами.
*   🛠 **Расширенные настройки:** Управление FastFlags, кастомные иконки и интеграция с Discord RPC.
*   ⚡ **Fox Engine:** Быстрое переключение между версиями клиента и встроенные фиксы задержки.
*   🛡 **Безопасность:** Открытый исходный код и отсутствие лишнего мусора в системе.

---

## 🛠 Технологический стек

*   **Язык:** C# / .NET
*   **База:** Bloxstrap Core
*   **Стиль оформления:** Glassmorphism / Neon Dark

---

## 🚀 Установка и запуск

1. Перейдите в раздел [Releases](https://github.com/Ramos1488/Foxstrap/releases/tag/v1.0.1).
2. Скачайте последнюю версию `Foxstrap.exe`.
3. Запустите файл и следуйте инструкциям установщика.
4. Настройте лаунчер под себя и нажимайте **Play**!
